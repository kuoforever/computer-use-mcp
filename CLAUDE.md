# Claude Code repository guide

Read and follow [AGENTS.md](AGENTS.md). The current task and project state are
in [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Required read order

1. `PROJECT_STATUS.md`
2. `docs/FULLCYCLE_INTEGRATION.md`
3. The source files and tests named by the active `GDA-FC-*` item
4. Layer owner documents only when required

Do not infer the active task from the branch name, old chat history, the broad
roadmap, or archived plans.

## Expected completion response

Report:

1. outcome;
2. modified files;
3. validation commands and exact results;
4. remaining limitations;
5. the next backlog item.

Do not claim live provider, desktop, application, or release evidence from
offline tests.
