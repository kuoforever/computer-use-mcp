# Claude Code repository guide

Read and follow [AGENTS.md](AGENTS.md). The current task and project state are
in [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Required read order

1. `PROJECT_STATUS.md`
2. The source files and tests named by the single active item
3. `docs/FULLCYCLE_INTEGRATION.md` for bridge or cross-repository work
4. Layer owner documents only when required

Do not infer the active task from the branch name, old chat history, the broad
roadmap, or archived plans.

If the canonical active item or exact next action explicitly points to a
historical Demo/HUD slice, follow the owner and evidence links named there;
consult the matching `HANDOFF.md` safe-resume note only for durable operational
context. No old Demo ID or handoff section independently authorizes resumption.

## Expected completion response

Report:

1. outcome;
2. modified files;
3. validation commands and exact results;
4. remaining limitations;
5. the next backlog item.

Do not claim live provider, desktop, application, or release evidence from
offline tests.
