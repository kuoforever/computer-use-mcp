# GDA-07 — Evidence-driven engineering discipline

> **Status: current candidate resume item; capability levels remain owner-controlled.**

- **JD tags:** testing, CI, evaluation, release engineering, observability,
  technical documentation.
- **Candidate bullet (ZH):** 建立 Design/Implemented/Offline/Provider/Desktop/
  Application/Release 分层证据模型，将 deterministic tests、真实运行、dated
  evidence、docs consistency 与 capability promotion 分离，避免用 mock 或文档
  细节冒充线上能力。
- **Candidate bullet (EN):** Established a layered evidence model separating
  design, implementation, offline, provider, desktop, application, and release
  claims, with deterministic gates and immutable dated records.
- **Evidence level:** repository-wide engineering process; individual capability
  levels remain owned by the dashboard.
- **Sources:** [capability dashboard](../../CAPABILITY_STATUS.md),
  [evaluation contract](../../EVALUATION.md),
  [AI-assisted development](../../AI_ASSISTED_DEVELOPMENT.md), and
  [release contract](../../RELEASE.md).
- **Do not claim:** test count as user impact, complete test coverage, or that CI
  alone proves real provider/desktop/application behavior.
- **Interview expansion:** discuss immutable evidence, negative results,
  pre-registration, documentation drift, and automatable claim checks.
