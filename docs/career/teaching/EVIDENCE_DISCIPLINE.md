# Evidence and claim discipline

> **Status: current module of teaching protocol v1.**

- Planned work remains planned.
- Offline tests cannot become provider, desktop, application, or release claims.
- Dated runs keep the exact environment, candidate, numbers, and limitations
  they observed.
- Repository evidence proves project behavior, not personal ownership. Confirm
  the user's contribution before producing a final resume bullet.
- Add a resume item only for a meaningful design, implementation, verified
  result, negative result, or postmortem—not after every conversational step.
- Never create a second learning or project tracker. Conversation teaches;
  owner documents track project truth; [resume evidence](../resume/) indexes
  selected facts.

For supervised desktop evidence, possible user input/focus intervention makes
the attempt invalid until a fresh observation and rerun separate interference
from a code defect.
